PARTICLE UNIVERSE

Interactive Particle Physics Simulation

Particle Universe is a real-time particle simulation environment built using JavaScript and HTML5 Canvas. It explores the behaviour of particles through physics-based interactions, dynamic rendering, and user-controlled forces.

---

Overview

The project provides an interactive environment where particles respond to gravity, collisions, boundaries, and external forces. The simulation is designed around a modular architecture, with separate components handling physics, rendering, input, and application control.

Core Features

- Real-time particle simulation
- Gravity and force manipulation
- Particle collision detection and response
- Boundary collision handling
- Mouse-based attraction and repulsion
- Dynamic particle generation
- Simulation pause and resume
- Particle reset and clearing
- Responsive interface

Technology

Component| Implementation
Structure| HTML5
Styling| CSS3
Core Logic| JavaScript
Rendering| HTML5 Canvas
Input Handling| Pointer Events API

Architecture

The application follows a modular structure to separate simulation logic from user interaction and visual rendering.

- Physics Engine — Handles particle motion, forces, collisions, and physical constraints.
- Spatial Grid — Organizes particles to improve collision detection efficiency.
- Renderer — Handles particle visualization and canvas updates.
- Input Controller — Processes mouse and touch interactions.
- Application Core — Coordinates the simulation loop and system components.
- Configuration — Stores simulation parameters and adjustable constants.

Getting Started

Clone the repository:

git clone <repository-url>

Navigate to the project directory:

cd Particle-Universe

Open "index.html" in a modern web browser or run the project using a local development server.
